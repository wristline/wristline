# 다른 사람이 쓸 때 어색한 부분 + 계정 뱃지 설계

기준: 워치 `wristline` 444efaf, 브릿지 `wristline-bridge` 743f9aa. 저장소 파일은 바꾸지 않음(읽기만 함).

## 요약 (3줄)

- 가장 어색한 건 **계정 구분**이에요. 지금 규칙은 이 사용자의 라벨(Work/Pro)에 맞춰져 있어서, 다른 사람은 라벨이 보통 이메일이에요. 그러면 두 계정이 똑같이 소문자 `j`로 보이거나, 기본 계정이 뒤로 밀릴 수 있어요.
- 그 밖엔 음성 읽기가 한국어/영어만 가정하는 점, macOS 설치 지원이 부족한 점, 한도 알림에 계정이 안 나오는 점 정도예요. 포트·경로·모델 같은 기본값은 대부분 맞게 되어 있어요.
- 뱃지 추천(결정 반영: 바꾸기는 워치에서): **처음엔 라벨 첫 글자를 자동으로 쓰고, 겹치면 다음 글자(이메일이면 도메인 첫 글자), 그래도 겹치면 숫자**. 워치가 한번 정한 글자를 기억해서 잘 안 바뀌게 해요. 바꾸고 싶으면 **워치 설정 → 계정 → 탭 → 글자·색 고르기**. 브릿지는 계정 id, 라벨, "기본 계정" 표시만 보내요.

## Part 2. 계정 뱃지 설계 (결정 반영: 바꾸기는 워치 설정에서)

### 정해진 것

- **브릿지**는 "누구인지"만 보내요: 계정 `id`, `label`, 그리고 새로 `primary`(기본 계정 표시). 글자·색은 보내지 않아요. CLI나 config로 뱃지를 바꾸는 방법은 만들지 않아요.
- **워치**는 계정 id마다 고른 글자와 색을 Prefs에 저장해요. 처음 쓰는 사람을 위한 자동 글자도 워치가 정하고 기억해요.

### 먼저 알아둘 제약

- **글자 크기가 아주 작아요.** 원 지름 9dp, 글자 7dp이고, 사용자 글꼴 크기를 따라 커지지 않아요. Wear OS 품질 기준(WO-V14)은 덜 중요한 글자도 10sp 이상, 글꼴 크기 설정 존중(WO-V1)을 요구해요. 그래서 이 글자는 "보조 표시"로 봐야 해요. 같은 정보가 다른 곳(사용량 화면의 라벨, TalkBack)에도 있어야 해요.
- **7dp에 들어가는 것**: 대문자 하나, 숫자 하나는 잘 보여요. 쉬운 한글 한 글자(회, 개)도 괜찮아요. 이모지는 모양보다 색으로 구분돼요. **두 글자와 단색 아이콘(가방, 플라스크)은 안 들어가요.** Material 아이콘은 20~24dp 기준으로 그려졌어요.
- **"동그라미 숫자/문자"는 이미 있어요.** 지금 흰 원 안에 글자를 넣는 방식이 곧 동그라미 문자예요. 유니코드 ①·Ⓐ를 원 안에 넣으면 원 안에 원이 생겨서 더 작아져요. 그래서 그냥 `1`, `A`를 넣어요.
- **색은 이미 다른 뜻으로 쓰고 있어요**(상태 점, 80% 노랑·95% 빨강, Claude 주황, Codex 파랑). 그래서 색은 **글자에 더하는 선택 사항**으로만 두고, 노랑·빨강 계열은 빼요. 색만으로 구분하면 색각 이상 사용자에게 안 보여요(WCAG 1.4.1).
- **TalkBack은 지금처럼 이름을 읽어요.** "Codex Work"처럼 제공자와 라벨(또는 별명)을 읽고, 표시 글자나 색은 읽지 않아요.
- **비슷한 사례**: Android 연락처나 Gmail도 사진이 없으면 "첫 글자 + 동그라미"를 써요. M3 "Badge"는 숫자나 상태용(6dp 점, 16dp 최대 4글자)이라 계정 이름표와는 용도가 달라요.

### 네 가지 방법 비교 (기본값을 고르는 기준)

| 방법 | 장점 | 단점 | 역할 |
|---|---|---|---|

| B. 번호 1·2·3 | 절대 안 겹쳐요. 제일 잘 보여요 | 뜻이 없어서 외워야 해요 | A의 마지막 대비책. 고르기 화면의 선택지 |

### 기본값(설정 0번)은 어떻게 정하나: 워치가 자동 배정하고 기억

**글자 고르는 규칙** (같은 제공자 안에서만 겹치지 않으면 돼요):

1. 정하는 순서는 기본 계정(`primary`) 먼저, 그다음 라벨 순, 그다음 id 순이에요.
2. 각 계정은 아래 후보 중 **아직 아무도 안 쓴 첫 글자**를 가져요. 여기서 "아무도"에는 지금은 안 보이지만 기억해 둔 계정도 포함돼요.
   - 각 단어의 첫 글자. 이메일이면 `@` 앞부분, 그다음 도메인 첫 글자.
   - 그다음 단어 안의 다음 글자들.
   - 그래도 없으면 숫자 1~9.
3. 영문은 대문자로 바꾸고, 한 "글자"는 사람이 보는 단위로 셉니다(한글 한 음절, 이모지 하나).
4. **한번 정한 글자는 기억해요**(Prefs, 계정 id 기준). 다른 계정이 로그아웃하거나 새로 생겨도 이미 정한 글자는 안 바뀌어요. 라벨이 바뀐 자동 글자만 다시 정해요.
5. 계정이 하나뿐인 제공자에는 지금처럼 표시를 안 해요. 계정 하나 쓰는 사람에게는 변화가 없어요.

### 워치 화면 흐름 (Settings → 계정 → 탭 → 고르기)

1. **설정 → 계정**: 어떤 제공자든 계정이 2개 이상일 때만 이 줄이 보여요. 오른쪽 작은 글씨로 "Codex 2, Claude 1" 같은 개수를 보여 줘요.
2. **계정 목록**: 제공자별 소제목(Claude / Codex) 아래 한 줄씩 `[뱃지+W] Work`, 아랫줄에 "자동" 또는 "직접 지정"을 보여 줘요. 기본 계정이 맨 위예요. 지금은 안 보이는 기억된 계정은 흐리게 맨 아래에 둬요.
3. **계정 탭 → 상세 화면**
   - 맨 위 미리보기: 실제 크기 뱃지와 크게 확대한 뱃지를 나란히 보여 줘요. 실제 크기에서 잘 보이는지 바로 확인할 수 있어요.
   - **글자**: "자동 (W)"를 맨 앞에 두고, 라벨의 글자들(W O R K), 숫자 1~9, 이모지 몇 개(🏠 💼 ⭐ 🎓 🧪)를 둬요. 한 줄에 3개씩, 버튼 하나가 48dp예요. **타이핑 없이 탭만** 해요.
   - 같은 제공자의 다른 계정이 쓰는 글자는 흐리게 해서 못 고르게 해요. TalkBack은 "W, Pro가 사용 중"이라고 읽어요.
   - **색**: 흰색(기본), 하늘, 초록, 주황, 자주, 파랑. 6개 원을 한 줄에 둬요. 글자색은 자동이에요(파랑만 흰 글자, 나머지는 검은 글자). 모두 대비 4.5:1 이상이에요. 노랑·빨강은 경고 색과 헷갈려서 뺐어요.
   - **이름(선택)**: 별명을 넣으면 워치에서 라벨 대신 보여 줘요(결정 질문 4). 기존 텍스트 입력(워치 이름 바꾸기와 같은 방식)을 그대로 써요.
   - **자동으로 되돌리기** 버튼이 맨 아래에 있어요.
4. 고르면 바로 저장되고, 뒤로 가면 모든 화면에 적용돼 있어요. 확인 버튼은 없어요(Wear 설정 화면들의 보통 방식).
5. 화면 문구("계정", "자동", "직접 지정", "색")는 설정 화면이라서 영어/한국어로 번역해요.

### 어디에 똑같이 보이나

- 워치 안에 "계정 표시" 한 곳(Prefs의 StateFlow, 테마 색 설정과 같은 방식)을 두고, 모든 화면이 여기서 글자·색·이름을 가져가요. 그래서 화면마다 따로 계산하지 않아요.
- **한도 카드, 세션 카드**: 지금처럼 뱃지+글자. 고른 색이 원 색이 돼요.
- **사용량 화면**: 계정 줄 앞에 같은 뱃지를 **새로 추가**해요. "W=Work"를 알려 주는 범례 역할이에요.
- **알림**: 알림 아이콘에는 합성 뱃지를 못 넣어서 글자로 보여 줘요. 그 제공자에 계정이 여러 개일 때만 부제에 `Codex · Work`를 넣어요. 한도 알림에는 꼭 넣고, 요청·완료 알림에도 같은 규칙을 써요.
- **빠른 질문 확인 화면**: 쓰이는 계정(기본 홈 계정)의 뱃지(선택 사항).
- **TalkBack**: 어느 화면이든 "Codex Work"(별명이 있으면 별명)로 읽어요.

### 기억하는 방법 (Prefs)

```kotlin
// 계정 id → 표시. auto=true는 워치가 자동으로 정한 것(라벨이 바뀌면 다시 정함)
@Serializable data class AccountMark(
    val provider: String,
    val label: String,      // 정할 때의 라벨(바뀌었는지 비교용)
    val mark: String,       // 한 글자
    val auto: Boolean,
    val color: String? = null, // 팔레트 이름. null = 흰색
    val name: String? = null,  // 별명(선택)
    val seenAt: Long,          // 마지막으로 본 시각. 자동인 것만 90일 지나면 정리
)
```

- SharedPreferences에 JSON 한 덩어리로 저장해요. 이미 kotlinx.serialization을 쓰고 있어요.
- "연결 끊기(Disconnect)"를 누르면 지금의 `Prefs.clear()`처럼 함께 지워져요. 백업에서도 빠져요(기존 규칙).

## 결정할 것 (추천 먼저)

1. **처음(설정 0번) 표시는?** → 추천: **라벨 글자 자동, 겹치면 다음 글자, 마지막엔 숫자. 한번 정하면 기억.** 뜻이 있고, 계정이 들락날락해도 글자가 안 바뀌어요.
2. **고를 수 있는 글자 종류는?** → 추천: **라벨 글자 + 숫자 1~9 + 이모지 5개.** 단색 아이콘은 7dp에서 안 보여서 빼요.
3. **색도 고르게 할까?** → 추천: **예, 6색(흰색 기본), 글자와 함께만.** 색만으로 구분하는 설정은 없어요.
4. **이름(별명)도 워치에서 바꾸게 할까?** → 추천: **예.** 기본 홈 계정에 라벨을 못 붙이는 문제(Part 1)가 CLI 없이 풀리고, 자동 글자도 별명에서 뽑아요.
5. **기본 계정 정렬은?** → 추천: **브릿지 `primary` 표시로.** 단어로 추측하는 규칙을 없애요.
6. **알림에 계정을 넣을까?** → 추천: **예, 계정이 여러 개인 제공자만.**
